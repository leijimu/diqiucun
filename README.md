# 地球村：数字游民账号清单

> 面向华人数字游民 / 云居民的一站式账号与工具清单：开户之前先看一遍，少踩坑、少返工。
>
> 最后更新：2026-10-01 · 本清单为经验整理，仅供参考，各服务政策经常变化，开户前请以官网为准。

---

## 0. 开局顺序（建议优先级）

刚开始云居民生活，按这个顺序一件件办，每一步都是下一步的前置条件：

1. **护照**：有效期 ≥ 6 个月，空白页充足
2. **一张能收国际短信的实体卡**：很多服务的 2FA 和注册验证只认实体号码
3. **主力邮箱 + 密码管理器 + 2FA**：账号体系的地基，先搭好
4. **Wise（或同类多币种账户）**：收款、换汇、日常消费
5. **VPN**：稳定上网是生产力前提
6. **第二身份/居留/税号**：按需逐步补齐

---

## 1. 身份与居留

- [ ] **护照**：检查有效期和空白页；部分国家要求入境时护照有效期 ≥ 6 个月
- [ ] **数字游民签证**：泰国 DTV、马来西亚 DE Rantau、西班牙、葡萄牙、爱沙尼亚等，各国收入证明要求不同
- [ ] **爱沙尼亚 e-Residency**：远程注册欧盟公司、开对公账户的常用跳板
- [ ] **各国 TIN（税号）**：如马来西亚 TIN，可线上申请；用途包括税务申报、部分金融开户
- [ ] **证件扫描件云端备份**：护照、签证、居留卡拍照存档，丢失时救命

## 2. 电话与短信

这是最容易踩坑的一环：很多服务把"能不能收到验证码"和"是不是 VoIP 号码"分开判断。

- [ ] **实体 SIM 卡**：如香港卡；只收短信、不能发送也够用——绝大多数验证场景只需要"收"
- [ ] **eSIM（保号）**：如 Saily 美国号码 eSIM，低成本长期持有美国号码收短信
- [ ] **eSIM（流量）**：如 Airalo，按目的地买流量包，落地即用
- [ ] ⚠️ **VoIP 大坑（实测）**：Telegram、WhatsApp、ChatGPT、Claude 明确拒绝 VoIP 号码注册；Apple、Instagram 可用。注册前先想好这个服务认不认虚拟号
- [ ] **号码组合建议**：一个 VoIP/低成本美国号（宽松服务）+ 一张实体卡（严格服务），分开用
- [ ] **Google Voice**：需要美国 IP + 美国实体号验证一次，之后可长期用

## 3. 网络

- [ ] **自建 VPN**：VPS + Xray（VLESS + REALITY），自己掌控、最稳
- [ ] **备用机场**：自建故障时的 Plan B，关键时刻能救命
- [ ] **代理网关**：家里多设备（电视、游戏机、旧电脑）走统一代理，一次配置全家受益
- [ ] **测速习惯**：从你真实所在的位置测，不要轻信服务商宣传的数字

## 4. 邮箱与账号体系

- [ ] **Gmail**：主力邮箱，大部分服务的首选注册/登录方式
- [ ] **Outlook**：备用邮箱，微软系服务用它更顺
- [ ] **Apple ID（多区）**：如美区 Apple ID，用于下载国区没有的 App；注册需境外号码验证（实测：香港实体号码一次通过）
- [ ] **密码管理器**：1Password / Bitwarden，全站唯一强密码
- [ ] **2FA**：Authenticator App 起步，重要账号上硬件 Key；恢复码离线保存两份

## 5. 银行与支付

- [ ] **Wise**：多币种账户、虚拟卡、国际汇款，数字游民标配
- [ ] **香港银行账户**：港币/美元出入、券商入金的常用中转
- [ ] **美元账户**：如经券商渠道（iFAST 等）的美元定存，美元有闲钱时别让它躺着
- [ ] **信用卡**：一张境外消费免货币转换费的卡，订机票酒店用
- [ ] **Stripe**：在线收款；注意需要对应国家/地区的注册主体
- [ ] **加密货币通道**：合规交易所出入金，作为备用资金通道

## 6. 税务与合规

- [ ] **搞清楚自己的税务居民身份**：住满 183 天规则、各国认定标准不同，先搞懂再行动
- [ ] **TIN 们**：按实际需要申请，不要为了"收集"而开
- [ ] **记账**：收入支出按币种记，报税季不抓瞎
- [ ] **咨询专业人士**：金额变大之前，花一笔咨询费比事后补税便宜

## 7. 域名与主机

- [ ] **域名**：Cloudflare Registrar / NameSilo，续费价透明的注册商
- [ ] **DNS + CDN**：Cloudflare，免费版对个人站已经足够
- [ ] **VPS**：除 VPN 外只跑轻量服务（问卷、静态页），别在上面堆重应用
- [ ] **静态托管**：Cloudflare Pages / Vercel，个人项目首选

## 8. 生产力与云服务

- [ ] **云盘**：Google Drive / iCloud，跨设备同步
- [ ] **笔记**：Notion / Obsidian，知识库随身带
- [ ] **代码托管**：GitHub，顺手也是作品集
- [ ] **日历与时区工具**：跨时区约会必备

## 9. 保险与健康

- [ ] **旅行保险 / 国际医疗保险**：如 SafetyWing、安联，长期在外别裸奔
- [ ] **常用药清单**：各国处方药政策不同，慢性病用药提前规划

## 10. 旅行

- [ ] **机票**：Google Flights 比价 + 航司官网出票
- [ ] **住宿**：Airbnb（长住议价）/ Booking（短住灵活）
- [ ] **常旅客计划**：固定一两个联盟攒里程
- [ ] **离线地图**：Google Maps 离线包，落地前下好

## 11. 备份与安全

- [ ] **3-2-1 备份**：3 份拷贝、2 种介质、1 份异地
- [ ] **账号恢复码**：打印或手抄一份，放家里
- [ ] **设备加密**：笔记本、手机全盘加密，边境检查不心慌
- [ ] **定期检查**：每季度过一遍本清单，补过期证件、续费域名、换弱密码
