## 八、进阶清单

上面七类解决"用什么"，下面解决"还缺什么"。

### 1. 开局顺序（建议优先级）

刚开始云居民生活，按这个顺序一件件办，每一步都是下一步的前置条件：

1. **护照**：有效期 ≥ 6 个月，空白页充足
2. **一张能收国际短信的实体卡**：很多服务的 2FA 和注册验证只认实体号码
3. **主力邮箱 + 密码管理器 + 2FA**：账号体系的地基，先搭好
4. **Wise（或同类多币种账户）**：收款、换汇、日常消费
5. **VPN**：稳定上网是生产力前提
6. **第二身份/居留/税号**：按需逐步补齐

### 2. 身份与居留

- [ ] **护照**：检查有效期和空白页；部分国家要求入境时护照有效期 ≥ 6 个月
- [ ] **数字游民签证**：泰国 DTV、马来西亚 DE Rantau、西班牙、葡萄牙、爱沙尼亚等，各国收入证明要求不同
- [ ] **爱沙尼亚 e-Residency**：远程注册欧盟公司、开对公账户的常用跳板
- [ ] **各国 TIN（税号）**：如马来西亚 TIN，可线上申请；用途包括税务申报、部分金融开户
- [ ] **证件扫描件云端备份**：护照、签证、居留卡拍照存档，丢失时救命

### 3. 网络

- [ ] **自建 VPN**：VPS + Xray（VLESS + REALITY），自己掌控、最稳
- [ ] **备用机场**：自建故障时的 Plan B，关键时刻能救命
- [ ] **代理网关**：家里多设备（电视、游戏机、旧电脑）走统一代理，一次配置全家受益
- [ ] **测速习惯**：从你真实所在的位置测，不要轻信服务商宣传的数字

### 4. 税务与合规

- [ ] **搞清楚自己的税务居民身份**：住满 183 天规则、各国认定标准不同，先搞懂再行动
- [ ] **TIN 们**：按实际需要申请，不要为了"收集"而开
- [ ] **记账**：收入支出按币种记，报税季不抓瞎
- [ ] **咨询专业人士**：金额变大之前，花一笔咨询费比事后补税便宜

### 5. 保险与健康

- [ ] **旅行保险 / 国际医疗保险**：如 SafetyWing、安联，长期在外别裸奔
- [ ] **常用药清单**：各国处方药政策不同，慢性病用药提前规划

### 6. 备份与安全

- [ ] **3-2-1 备份**：3 份拷贝、2 种介质、1 份异地
- [ ] **账号恢复码**：打印或手抄一份，放家里
- [ ] **设备加密**：笔记本、手机全盘加密，边境检查不心慌
- [ ] **定期检查**：每季度过一遍本清单，补过期证件、续费域名、换弱密码
